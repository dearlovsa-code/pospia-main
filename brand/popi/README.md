# 포피(POPI) 캐릭터 가이드

포스피아 브랜드 캐릭터 자료 모음. 인스타 마케팅 세션(2026-11)에서 만든 설정과 그림을 홈페이지 등 다른 작업에서도 쓰도록 옮겨 둔 것이다.
이 폴더(`brand/`)는 `.assetsignore`에 들어 있어 사이트에 그대로 공개되지 않는다. 홈페이지에 쓸 그림은 `assets/img/`로 복사(WebP)해서 쓴다.

## 1. 포피는 누구인가

- **포스피아 대표(CEO)**. 결제가 멈추지 않게 매장을 지키는 인외(人外) 캐릭터.
- **생김새**: 사람의 몸 + 머리 대신 **흰색 입체 포스피아 로고 마크**(육각형 집 모양 안에 P). **눈·코·입이 없다.**
- **옷**: 검은 정장, 흰 셔츠, **금색 넥타이**, 금색 포켓스퀘어, 흰 장갑, 검은 구두. 키 크고 어깨 넓은 체형.
- **성격**: 말수가 적고 무표정하지만 따뜻하다. 로고가 반짝이는 게 자랑. 말투는 짧게, 쉼표 많이 ("결제는, 멈추지 않는다." "…맛있군.").
- **감정 표현**: 얼굴이 없으므로 몸짓·포즈·주변 효과로만. 결제 승인 순간 로고가 금빛으로 빛남("띠링").
- **약점·개그 포인트**: 로고 머리가 빛을 반사해 사진이 하얗게 날아감(EP 단체사진), 음식은 로고의 P 구멍으로 먹음(EP 회식), 얼굴 결제(페이스사인)를 못 함.
- **어린 시절**: 1998년, 노란 책가방을 멘 초등학생 포피(로고 머리가 크고 둥글게). 마을버스에 100원을 내던 아이 → 지금 100원 단말기를 건네는 대표.

## 2. 함께 나오는 인물

| 이름 | 머리 | 옷차림 | 성격 |
|---|---|---|---|
| **포스 양** | 흰색 각진 포스기 모니터 | 아이보리 주름 블라우스형 반바지 점프수트, 허리 끈, 검은 크로스백, 스트랩 샌들 | 부드럽고 친숙함. 카운터 담당 |
| **키오스크 양** | 세로로 긴 은색 테두리 키오스크 | 회색 체크 크롭 블레이저, 검은 탑, 검은 와이드 슬랙스, 힐 | 스마트하고 빠름. 매장 입구 담당 |
| **테이블오더 양** | 얇은 흰 프레임 가로형 태블릿 | 짧은 흰 스포츠 탑, 흰 줄 차콜 조거 팬츠, 은색 운동화 | 스포티하고 활발함. 테이블 담당 |

- 세 사람 모두 **사람 얼굴·머리카락 없음, 화면에 표정도 넣지 않는다**(화면은 빈 검은 유리 + 빛 반사). 사용자가 표정 버전을 "개구리다"며 거절함.
- 직원 셋(툰 조연, 사람): 짧은 머리 흰 셔츠 남자 / 단발 베이지 니트 여자 / 안경 회색 가디건 남자.

## 3. 그림 규칙

- 그림체: **한국 웹툰 스타일, 깔끔한 선화와 부드러운 셀 채색, 밝은 미색·금색 톤**.
- 배경은 **단순하게**: 단색에 가까운 배경, 소품 최소, 꽃·하트·반짝이·빛줄기·속도선 같은 장식 금지("화려해서 눈이 아프다"는 피드백).
- 매장 장면은 출입문·줄·계산대 위치를 먼저 정하고 모든 컷이 같은 배치를 따른다.
- 거절된 방향: 코드(SVG)로 직접 그린 포피, 어두운 배경의 시크한 포피, 기기 화면에 표정 넣기.
- 브랜드 색: 남색 `#2f4152`, Blue Fusion `#496175`, 금색 `#d6cd94`, 미색 `#f0eee9`, 연보라 `#e9e3ec`, 진한 바탕 `#1c1b19`.

## 4. 파일

| 경로 | 내용 |
|---|---|
| `popi-main.webp` | **기준 그림**(넥타이 고쳐 매는 상반신). 새 그림을 만들 때 항상 참고 이미지로 넣는다 |
| `poses/*.webp` | 배경 없는(투명) 포즈 모음. 이름이 곧 동작 (예: `pose-terminal` 단말기 들고 엄지 척, `pose-bow` 인사, `pose-present` 소개, `pose-toolbox` 공구 가방 출동, `pose-teacher` 안경·지시봉, `pose-listen` 메모하며 듣기 등) |
| `cast/{popi,pos,kiosk,tablet}-{front,side,back}.webp` | 네 캐릭터 정면·옆·뒤 레퍼런스 |
| `cast/device-ladies-lineup.webp` | 포스 양·키오스크 양·테이블오더 양 단체 설정 그림 |
| `scenes/` | 대표 장면(네 캐릭터 군무, 로고 얼굴 공개, 단체사진) |

인스타 캐러셀은 포즈를 **표지·핵심 장·마지막 신청 장에만** 얹었고, 세트마다 다른 포즈를 썼다. 홈페이지에서도 같은 포즈를 여러 곳에 반복하지 않는 게 좋다.

## 5. 새 그림 만드는 법

- **gpt-image 스킬**(ChatGPT 구독, Codex CLI + Sign in with ChatGPT). API 키는 쓰지 않는다. 새 클라우드 기기에서는 스킬 설치와 ChatGPT 로그인이 다시 필요하다(허용 주소 `auth.openai.com`, `chatgpt.com`).
- 지시문 앞부분 예시:
  > 한국 웹툰 스타일, 깔끔한 선화와 부드러운 셀 채색. 첨부한 캐릭터 '포피'와 같은 인물: 사람의 몸에 머리 대신 흰색 입체 포스피아 로고 마크(육각형 집 모양 안에 P), 얼굴(눈·코·입) 없음. 검은 정장, 흰 셔츠, 금색 넥타이, 금색 포켓스퀘어, 흰 장갑, 검은 구두.
- 투명 배경 포즈는 `--background transparent`. 글자·말풍선은 그림에 넣지 않고 나중에 얹는다(AI가 한글을 깨뜨림).
- 영상: 힉스필드(Higgsfield) Genjutsu 모션 트랜스퍼로 네 캐릭터 군무 영상을 만든 적 있음. 크레딧이 제한돼 있어 생성 전 견적을 보여 주고 허락을 받는다.

## 6. 문구를 쓸 때 지킬 것

- 확인된 사실만: 카드단말기 100원 · 약정 없음 · 폐업 시 단말기만 반납 · 신규·예비 창업 소상공인 대상 · 1577-7107(평일 09:30–18:30). 통신 함께 설치 지원금 **최대 90만원**(2026-11-20 변경).
- **회사소개·택스리펀드 사이트의 "고객후기"는 임의로 만든 것이라 광고·캐릭터 콘텐츠에 쓰지 않는다.** "5만 곳 이상", "2010년부터" 같은 숫자도 사용자 확인 전에는 새로 늘려 쓰지 않는다.
- 수익 구조는 언급하지 않는다(사용자 요청).
